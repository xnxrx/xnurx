18 — Baris origin pada dialog JS saat navigasi masih pending

URL asli halaman… Origin asli… Tujuan pending… (port di-DROP, navigasi menggantung)

VULNERABLE: baris judul dialog menyebut www.google.com (atau host tujuan lain) padahal dokumen pemilik dialog adalah origin asli di atas.
SECURE: dialog menyebut origin asli di atas, atau tidak menyebut host sama sekali (mis. Firefox: “This page says”), atau dialog ditekan browser selama navigasi pending.
Baseline aman = tombol KONTROL: mekanisme (navigasi pending) dihapus, host yang disebut harus sama dengan origin asli. Bandingkan dua tangkapan layar itu. 


  
Setelah dialog ditutup, navigasi tetap menggantung. Tutup tab atau tekan Stop untuk keluar.
     Hanya alert(); tidak ada masukan apa pun yang diminta.
