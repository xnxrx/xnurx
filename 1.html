Mekanisme: window.open() ke port yang paketnya di-DROP pada host nyata. Handshake TCP tidak pernah selesai → navigasi tetap pending → dokumen about:blank awal popup masih milik opener → opener menulis isinya.

VULNERABLE: address bar popup menampilkan padahal badan halaman melaporkan location.href aslinya about:blank.

SECURE: address bar popup menampilkan about:blank / kosong selama navigasi belum commit; URL target baru muncul setelah dokumen server benar-benar dimuat.

Cara membaca: satu screenshot berisi address bar popup + badan popup sudah cukup untuk memutuskan.
