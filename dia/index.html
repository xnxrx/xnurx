Dia (macOS) — origin-display probe set

10 arm + 1 lengan kontrol. Tiap file = satu mekanisme, punya predikat, oracle, dan perilaku-aman-yang-diharapkan sendiri. Ini instrumen ukur untuk browser milik sendiri, bukan kit phishing.

Etika — tidak bisa ditawar. Jalankan hanya di mesin & browser sendiri. Tidak ada satu pun file di sini yang memuat form, kolom kredensial, fetch/beacon/WebSocket, service worker, atau tiruan identitas organisasi. Label www.google.com dipakai sebagai string tak-berbahaya. Berhenti di predikat (tampilan ≠ kenyataan) → screenshot → laporkan. Jangan pernah diarahkan ke pengguna lain.

Kenapa arm-arm ini, bukan yang lain

Dia sudah menerbitkan dua perbaikan di kelas ini — dan sebuah patch adalah oracle gratis:

Sumber: diabrowser.com/security/bulletins. Aturan emas: fix dibuat per-PERMUKAAN, cacatnya per-INVARIAN → tebakan pertama selalu permukaan tetangga yang tidak ikut dipaku.

Cara menjalankan

  1. Buka di Dia (macOS). Catat versi persisnya (Dia → About) — tanpa versi, hasilnya tidak bisa dipakai.
  2. Jalankan 00-control.html dulu. Kalau kontrol ikut "berhasil", berhenti: setup-nya yang salah.
  3. Baru jalankan arm-nya satu per satu. Satu arm = satu variabel.
  4. Knob port: :9090 harus di-DROP (paket dibuang → menggantung lama). Kalau muncul error page seketika, port itu me-REFUSE → ganti :8443/:8080/:82. Salah pilih di sini = vonis "tidak rentan" yang palsu.
  5. Bukti = screenshot bilah/permukaan berdampingan dengan panel origin asli (video untuk 07/08/09).
  6. Hasil negatif juga dicatat (arm + versi + tanggal). Sel mati hari ini adalah baseline untuk rilis berikutnya.

Melaporkan

Program: HackerOne — hackerone.com/bcny (The Browser Company / Dia). Baca policy & scope-nya sebelum submit. Kelas = origin/UI spoofing (CWE-451/290). Bingkai laporannya sebagai "permukaan X menyebut origin A sementara dokumen yang meminta adalah B", sertakan lengan kontrol, versi Dia, dan perilaku-aman yang diharapkan. Kalau arm-mu adalah tetangga dari CVE-2025-15032 / CVE-2025-13132, katakan itu: laporan bypass-of-fix ditriase lebih cepat.
