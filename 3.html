3 — Hang via rantai redirect tak berujung (Knob A)

URL asli halaman ini:

Mekanisme: rantai 60 hop redirect, jauh di atas batas ~20 hop browser. Navigasi tetap pending selama seluruh rantai (hop x RTT) dan berakhir di halaman error, bukan commit. Selama itu about:blank awal popup masih milik opener.

VULNERABLE: address bar popup menampilkan padahal badan halaman melaporkan location.href aslinya about:blank.

SECURE: address bar popup menampilkan about:blank selama rantai berjalan, lalu halaman error redirect — URL rantai tidak pernah diatribusikan ke dokumen tulisan opener.

Catatan jaringan: bila host di bawah sedang mati, ganti konstanta HANG/GOOD ke https://httpbingo.org/redirect/60 atau https://nghttp2.org/httpbin/redirect/60 (jalur kode tidak berubah).

Satu-satunya variabel yang berubah antara dua tombol adalah panjang rantai redirect.
